后续实际运行入口
- 打开 Assets/Scenes/RoyalFortressGameplay.unity，点击 Play。
- 编辑器命令行 -executeMethod FortressBuildVerification.Build 可构建验收程序。
- 验收程序参数：
  -fortress-smoke-test -fortress-test-output <输出目录>
- 验收脚本会发送合成 UI 拖放事件，检查预览不扣钱、取消、无效位置、
  已占用坑位、建塔扣费、余额不足、实际敌人受伤/击杀、波次、漏怪及重开，
  并保存 JSON 和游戏截图；正常游戏中不会自动运行。
