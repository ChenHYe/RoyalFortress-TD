# 地图取景与悬浮 UI

地图是可缩放、可平移的 2D 关卡。地图相机始终使用完整窗口，
小型状态条位于顶部，塔卡和波次按钮悬浮于底部，没有额外预留上下或左右空白区。

## 操作

- 滚轮：以鼠标位置为中心平滑缩放；到地图边缘时优先保证相机留在地图内。
- 左键按住地图拖动：平移地图，松手停止；从UI区域按下不会带动地图。
- WASD / 方向键：平移地图。
- Home 或右下角“复位”：恢复地图中心与默认缩放。
- 右下角 + / −：以画面中心为缩放中心。100% 表示当前窗口下最远取景。
- 拖塔卡时冻结地图导航；Esc / 右键取消后可继续导航。

状态条、塔卡和按钮拦截其区域的地图操作，透明间隙允许点击/拖动地图。
如果坑位位于悬浮卡栏下方或画面外，先平移或缩放地图使它进入可操作区域。
金币、生命和波次逻辑与相机独立；更换取景不会改变塔、敌人或路线的世界位置。

## 取景边界

`MapCameraController.mapRenderer` 指向该关背景精灵，使用其世界坐标包围盒约束相机。
最远取景同时受 `maximumSize`、地图高度与地图宽度/窗口比例限制。
因此在 4:3、16:9 或宽屏窗口下都会以地图覆盖画面，多余部分可以通过平移查看。
不会为了显示完整张地图而引入两侧留白。窗口尺寸改变后重新约束取景范围。

`minimumSize`、`maximumSize`、`startSize` 是正交相机半高度（世界单位）。
`zoomSpeed` 控制每格滚轮的缩放幅度；`zoomResponse` 控制过渡速度；
`keyboardSpeed` 控制键盘平移速度。参数可在主摄像机 Inspector 调整。

## 后续地图

当前美术仍是示例地图。新关卡可以比一个屏幕大：

1. 为该关创建背景，并把主相机的 `mapRenderer` 指向它。
2. 布置该关的路径点、出怪口、终点和建塔位，更新波次与建造控制器引用。
3. 按地图尺寸调整缩放上下限和初始取景；不需要改变 HUD 或金币逻辑。

这次没有新增地图编辑器、地图生成器或触摸手势。
# 暂停菜单

游戏内按 Esc 或点击右上角「菜单 Esc」暂停；再按 Esc 或点击「继续游戏」恢复。
菜单还提供「重新开始」和「返回地图选择」。左上角只显示地图名，移除了直接切图按钮。

暂停会停止战斗、出怪和天气倒计时，取消拖塔，屏蔽建造、地图拖动、缩放与键盘平移。
重开与返回地图选择会恢复正常时间，避免新场景停留在暂停状态。
