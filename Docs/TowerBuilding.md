# 点击地基建造法师塔

工程：`C:\Users\chy\My project`，场景：`Assets/Scenes/RoyalFortressGameplay.unity`。

## 现在怎样试

1. 在 Unity 底部 Project 中展开 Assets → Scenes，双击 RoyalFortressGameplay。
2. 点顶部 Play，再点击 Game 画面。
3. 地图上有 7 个带小加号的石台，左键点击任意空石台。
4. 菜单显示箭塔、投石塔、法师塔、冰霜塔。点击紫色的“法师塔／建造”。
5. 塔立即出现在所选地基，播放待机动画；菜单关闭，加号消失。这块地基不能再造第二座塔。
6. 继续选择其他空石台即可再造塔，也可点击右下角按钮开始一波敌人。

箭塔、投石塔、冰霜塔目前为灰色“未开放”。菜单中的关闭按钮、Esc 或点击地图空白处可取消选择。滚轮缩放、中键/右键拖动地图仍可使用；菜单跟随所选塔位并限制在视口内。

当前步骤实现选地基、开菜单、建造与占位。建塔暂时不扣金币，法师塔播放已有待机动画；索敌、投射物、攻击伤害、升级和拆除尚未接入。原有波次、敌人路线和 Home 扣血继续保留。

建造发生在 Play 模式中，停止运行后会回到空地基状态。重新开始关卡也会清空已造塔，这是本关运行状态的重置。

## 地基在编辑器的什么位置

Hierarchy → `Build Sites` 下是 `Build Site 01`～`Build Site 07`，分别对应背景上 7 个石台。每个对象包含：

- `BuildSite`：记录塔位名称、建造锚点与占用状态。
- `PolygonCollider2D`：与地基形状匹配的椭圆点击区域。
- `Empty Site Plus`：空地基加号提示。
- `Selection Ring`：鼠标经过与选中时的轮廓。
- `Tower Ground Anchor`：塔建成后底座所在位置。

如需调整地基，先退出 Play，在 Scene 中选中相应 Build Site，用 W 拖动，保持 Z=0。整座地基与它的点击区域、加号、锚点会一起移动。若只需修正塔底对齐，调整该地基的 Tower Ground Anchor 子对象即可。

`Tower Build Controller` 管理七块地基与法师塔 Prefab。菜单位于 `HUD Canvas` → `Tower Build Menu`，运行时在选中地基后显示。建好的实例位于 `Built Towers` 下。原来用于展示的 Demo Towers 已在此玩法场景中隐藏，避免出现一座无需建造的预放塔；原始 RoyalFortress 展示场景保留。
