王国边境 双塔 Unity 模块
版本 v2 | 2026-10-21

快速开始
1. 使用 Unity 2022.3.62f3c1 创建或打开一个使用内置渲染管线的 2D 工程。
2. 在菜单选择 Assets > Import Package > Custom Package，选择本交付目录中的 .unitypackage，保留包内文件并导入。
3. 等待脚本编译完成，在顶部菜单选择 Kingdom Border > 双塔 > 打开演示场景。
   也可直接打开 Assets/_Project/TwinTowers/Demo/TwinTowerDemo.unity。
4. 点击 Unity 顶部 Play。Game 视图建议选择 16:9，能看见两座塔、道路和底部控制台。
5. 演示默认自动生成训练傀儡。左边冰霜塔圆形范围内群体减速，右边法师塔发射带光环、拖尾和命中扩散的奥术飞弹。包内演示只是试验场，不是完整游戏地图。

演示操作
- 暂停演示/继续演示：暂停或恢复时间；不修改 Unity 项目的全局配置文件。
- 生成一个敌人：生成一个测试傀儡。暂停中生成的敌人会在继续后移动。
- 重置试验：清空敌人、子弹、命中效果和计数，重新开始生成计时；保留当前自动生成、护甲选择和塔开关。
- 冰霜塔开启/关闭、法师塔开启/关闭：切换对应塔攻击，同时查看它的参数。
- 护甲 60%/0%：只影响之后生成的敌人；重甲靶生命 220，普通靶生命 125，便于观察而非最终关卡平衡数值。
- 自动生成：开启/关闭后续自动生成；不会移除已经生成的敌人。
- 范围显示/隐藏：显示索敌范围；关闭法师塔不清空已发出的子弹；关闭冰霜塔会解除该光环。
- 想观察冰霜恢复：关闭法师塔，观察敌人进入冰霜圆变蓝减速、出圈后恢复；关闭冰霜塔也会解除该塔的全部减速。

怎么修改塔参数
在 Project 窗口打开 Assets/_Project/TwinTowers/Data/：
- MageSettings.asset 为法师塔参数。
- FrostSettings.asset 为冰霜塔参数。
- ArrowSettings.asset 为箭塔参数。
- ArtillerySettings.asset 为投石塔参数。
选中文件，在 Inspector 修改；字段带有中文 Tooltip，鼠标悬停可查看解释。
建议在退出 Play 后修改资源并保存。直接修改 ScriptableObject 资源可能在结束 Play 后保留，请自行记录想要保留的参数。
场景内和从同一预制体生成的塔默认共享同一参数资源。要独立调某座塔，先复制参数资源，再拖到该塔的 Definition 槽。

参数说明与默认值
名称 | 法师塔 | 冰霜塔 | 箭塔 | 投石塔 | 含义及单位
damage | 28 | 不使用（0） | 16 | 38 | 每发基础生命点伤害；冰霜光环不造成伤害。
range | 4.2 | 1.85 | 4.0 | 3.6 | 索敌/光环半径，以塔根节点为圆心，单位：Unity 世界单位。
attackInterval | 0.9 | 不使用 | 0.55 | 1.7 | 两次发射最小间隔，秒；冰霜光环持续生效。
projectileSpeed | 9 | 不使用 | 12 | 6.5 | 子弹速度，世界单位/秒；冰霜不发子弹。
armorPenetration | 0.75 | 0 | 0.1 | 0.2 | 忽略护甲的比例；0.75 = 忽略 75% 护甲。
splashRadius | 0 | 0 | 0 | 1.15 | 命中点溅射半径；投石塔对半径内全部敌人造成同等伤害。
slowFraction | 0 | 0.45 | 0 | 0 | 减去基础速度的比例；0.45 = 减速 45%，余速 55%。
slowDuration | 0 | 不使用（0） | 0 | 0 | 冰霜出圈即解除，不采用命中后的持续时间。
magicColor | 紫色 | 青色 | 琥珀 | 石色 | 飞弹/光环颜色，没有单位。
displayName、kind | 法师/Mage | 冰霜/Frost | 箭塔/Arrow | 投石/Artillery | 名称及行为类型；Frost 为范围光环，其余为弹体攻击。
本表“名称”是 Inspector 中的字段；各塔列是模块默认值；“含义及单位”说明算法和取值。“不使用”表示该行为不读取此参数，不是缺失数据。所有数值是试验场起步配置，不是完整关卡平衡结论。

伤害与减速规则
护甲字段 armorPercent 使用百分数，60 表示减伤 60%；有效范围 0—95。
实际伤害 = 基础伤害 × [1 - 护甲百分数/100 × (1 - 护甲穿透比例)]。
例如 40 点伤害、护甲 60、穿透 0.75，实际伤害为 34；不是把护甲直接减去 75。
索敌优先路径进度最靠前者，进度相同时优先距离较近者；只在射程内选取活着且启用的敌人。已经发出的追踪弹会继续追击，超时或失去活目标自动回收。
冰霜光环规则：以塔根节点为圆心，以 range 为半径，使用敌人根节点的 XY 位置判断，圆的边界也算在内。圈内所有活敌人持续减速，没有逐个索敌、弹体或命中等待；出圈、关闭塔、禁用组件或销毁塔会移除该来源的减速。多个光环只取最强减速，不相乘；更强光环移除后，仍在范围内的较弱光环接替。最多减速 90%。
默认半径 1.85 与试验场塔位配合，圆覆盖附近道路的一小段。拖动塔位置或修改 range 可调整范围；实际淡青色圆和玩法半径保持一致，不需要手工缩放光环子物体。
法师飞弹表现：发射闪光、旋转符环、明亮核心、两个环绕光点、渐隐紫色拖尾及命中扩散。表现不改变伤害公式。

在自己的场景中使用
1. 从 Prefabs/ 拖入 MageTower.prefab 或 FrostTower.prefab，不需要手工给子弹、图片或参数重新接线。
2. 在测试敌人上使用 EnemyAgent。TrainingEnemy.prefab 已配置图片及该组件。
3. 若用本包路径移动，调用 EnemyAgent.Initialize(生命, 护甲百分数, 基础速度, Vector3[]路径点)。路径至少两个点，起点会自动设置。
4. 若已有自己的移动系统，可把路径传为 null，使用 EnemyAgent.CurrentSpeed 控制移动；不要让两个脚本同时写位置。生命、伤害、死亡和金币的接入由主工程适配，不能仅贴图片就自动接入已有敌人系统。
5. EnemyAgent.Died 只在击杀时触发，可订阅来发金币；ReachedExit 是到终点事件，应由主工程决定扣血。演示计数不代表正式经济或生命系统。
6. 不用添加碰撞体，不用配置 Tag、Layer、Physics 矩阵、主摄像机标签或第三方服务。伤害依赖 EnemyAgent 的注册表，不依赖 Physics2D。
7. 导入路径是 Assets/_Project/TwinTowers。使用 Unity 编辑器移动资源以保留 .meta；若整体更改根路径，需同步 Editor/TwinTowerMenu.cs 中的 Root，否则菜单无法找到场景。拖拽预制体本身不依赖该菜单。
8. 本包不修改 ProjectSettings、Packages 或构建列表；演示通过场景内引用连接相机和塔，不要求全局单例。

文件结构
Runtime/ 核心脚本及飞弹效果；Materials/ 本包奥术拖尾材质；Data/ 可编辑参数；Prefabs/ 两种塔、追踪弹和训练敌人；Art/ 像素素材；Demo/ 场景和演示控制；Editor/ 便捷菜单；Documentation/ 本说明及来源。
本包不包含主工程的库缓存、课程资料、MCP 工具包、其他依赖或验证辅助脚本。

兼容性及已知边界
- 验证目标为 Windows 上的 Unity 2022.3.62f3c1、内置渲染管线；实际通过情况见交付目录的测试记录。
- URP、HDRP、Unity 6、移动端和其他系统未验证，不宣称兼容。接收者使用不同版本时应先在新工程测试。
- UI 使用系统动态字体；Windows 优先微软雅黑，其他系统尝试 PingFang SC、Noto Sans CJK SC，再退回 Arial。缺少中文字体的设备需自行安装或替换字体。
- 采用 Unity 原生 SpriteRenderer、TrailRenderer 和 IMGUI，无第三方包；手动精简过 Unity 内置模块的工程需保留 IMGUI、ParticleSystem（TrailRenderer）、ImageConversion 等内置模块；演示 UI 为桌面鼠标设计。
- 两张塔图为 AI 生成的像素风静态素材；使用 Point 采样、无 Mipmap，源图不是严格的 64×64 小像素网格。全游戏统一像素密度和角色美术留在后续美术阶段完成。
- 本阶段不包含建造扣费、升级、完整波次、胜负或正式地图；这些仍按 Plan.txt 后续阶段执行。
