双塔模块来源记录
日期：2026-10-21

需求来源：本项目用户关于中世纪魔法像素塔防、法师塔和冰霜塔优先、Unity 可操作包的要求及确认；第一版计划.docx 的两种塔职责设计。
脚本、光环/符环纹理、飞弹拖尾与爆发效果、训练傀儡示意图、地面和道路纹理：本项目编写/程序化绘制，没有使用外部游戏资产包。训练傀儡是功能测试素材，不代表最终怪物美术。
MageTower.png 与 FrostTower.png：2026-10-21 使用 Codex 内置 image_gen 生成，透明背景；原件在项目 assets/source，生成提示词见项目 assets/licenses/1021_双塔素材来源_v1.md。使用的是 AI 生成素材，没有套用某第三方素材包的许可声明。
ArrowTower.png、ArtilleryTower.png 与 StoneProjectile.png：2026-10-23 使用 Cursor image_gen 参照法师/冰霜塔立绘风格生成后去背导入；石块投射物为独立像素岩石精灵。同日重做箭塔为棕色木结构以区分投石塔，并按法师塔内容包围盒收敛体量与像素简化。
Unity 内置默认 Sprite 材质和系统字体由接收者本机 Unity/操作系统提供，未重新分发系统字体文件。
